# Arquitectura

Las rutas de módulo de esta página son relativas a `addons/ProfessionReagents/src/`. Los scripts de datos, las pruebas y la documentación viven junto a `src/` en el proyecto del addon. [Estructura del repositorio](../../../docs/ARCHITECTURE.md)

La instalación local contiene `_forever_/Wow.exe` con versión **1.60.1.70938** y el producto `wowf` en `.build.info`. La edición Camelot de LibProfessionDB y el entorno de desarrollo de Atraeau declaran **16001**. El TOC usa `AllowLoadGameType: camelot`. La interfaz de Blizzard del mismo build usa esa etiqueta en addons como `Blizzard_Gamepad`. [LibProfessionDB](https://www.curseforge.com/wow/addons/libprofessiondb/files/9619259) · [Atraeau](https://github.com/Atraeau/WoW-Addons) · [Blizzard_Gamepad.toc](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_Gamepad/Blizzard_Gamepad.toc)

| Módulo | Responsabilidad |
| --- | --- |
| `Database/Forever.lua` | Índice estático por ItemID con metadatos de origen, estadísticas y catálogo localizado |
| `Database/ReagentIndex.lua` | Valida identificadores y reduce los ingredientes a un conjunto por profesión durante la generación |
| `Services/ProfessionService.lua` | Valida y prepara los conjuntos con y sin iconos y aplica el orden del idioma mediante `C_Intl.GetSortKey` si está disponible |
| `UI/Tooltip.lua` | Resuelve el ItemID, deduplica y añade las líneas al tooltip nativo |
| `Config/Settings.lua` | Valida las preferencias persistentes y las comparte entre la categoría nativa de Opciones > Addons y `/pr` |
| `Locales/` | Cadenas de la interfaz. `enGB` y los idiomas adicionales usan inglés |
| `Core/Init.lua` | Inicializa una vez con `ADDON_LOADED` y muestra `/pr status` |

Los grupos de profesiones idénticos comparten una tabla. Se ordenan y se preparan los textos al iniciar el addon. El callback hace una búsqueda por ItemID y escribe una sección en tiempo proporcional al número de profesiones. Se usa un frame de inicio, una tabla débil para el estado de cada tooltip y cuatro booleanos en SavedVariables.

## Hooks y ciclo de vida

- **Ruta principal.** `TooltipDataProcessor.AddTooltipPostCall(Enum.TooltipDataType.Item, callback)` se ejecuta después de las líneas estructuradas de objeto y antes del `Show()` de Blizzard. El código toma primero `tooltipData.id`, que identifica el objeto del tooltip incluso si un enlace describe un resultado de receta diferente. Como alternativa, lee `tooltipData.hyperlink` o usa `GetItem()` si existe. [TooltipDataHandler.lua](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_SharedXMLGame/Tooltip/TooltipDataHandler.lua) · [TooltipUtil.lua](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_SharedXMLGame/Tooltip/TooltipUtil.lua)
- **Limpieza y caché.** El addon detecta y engancha `OnTooltipCleared` una vez por frame. Un nuevo callback tras la limpieza vuelve a renderizar el mismo objeto. `GameTooltip` reconstruye por su cuenta al recibir `TOOLTIP_DATA_UPDATE`. Si el cliente todavía no expone un ID o enlace, el addon espera al siguiente procesamiento nativo. `C_Item.GetItemInfo` y `GetItemInfoInstant` existen en el build. El addon resuelve el ID sin depender de que lleguen a la caché el nombre o la descripción. [GameTooltip.lua](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_GameTooltip/Mainline/GameTooltip.lua) · [ItemDocumentation.lua](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_APIDocumentationGenerated/ItemDocumentation.lua)
- **API opcional.** Si falta el procesador moderno, se intenta el script de objeto solamente en frames que exponen `HasScript("OnTooltipSetItem")`, `HasScript("OnTooltipCleared")` y `GetItem()`. Se verificó esta alternativa con mocks. El camino esperado en Forever es el procesador moderno. [Captura de desarrollador de Forever](https://github.com/Thunderz96/forever-addon-kit)
- **Integración.** El addon ignora frames prohibidos, valores secretos y bloques de objeto secundarios. Usa `AddLine()` y las fuentes del tooltip. Se sirve de los métodos nativos para el ciclo de vida, la posición y el resto del contenido. [GameTooltip.xml](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_GameTooltip/Mainline/GameTooltip.xml) · [FrameScriptDocumentation.lua](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_APIDocumentationGenerated/FrameScriptDocumentation.lua)

`GetBuildInfo()` y `GetLocale()` se verificaron en la API exportada de Forever. La consulta a Warcraft Wiki devolvió HTTP 403, por lo que las decisiones de API se basaron en el código de interfaz de Blizzard archivado en la revisión `bebcb6b` y en los volcados de Forever. El addon es gratuito, visible y funciona sin red, telemetría ni publicidad.
